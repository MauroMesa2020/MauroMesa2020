### 🤖 Code Agent with Nodes
**Status:** Research / In Progress

A research project focused on building AI agents from scratch, without relying on agent frameworks. It explores graph-based architectures where each node represents an action, such as LLM invocation, tool execution, or workflow termination.

**Technologies:**
`Python` `LLMs` `Graph-based Architecture` `Tool Calling`

[Repository](https://github.com/MauroMesa2020/code_agent_w_nodes)

**Technologies:**
